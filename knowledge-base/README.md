## Engineering principles

1. **Correct before fast:** compare complete results, including missing and duplicate rows.
2. **Reproducible over decorative:** provide code, fixtures, tests, and setup instructions.
3. **Bounded claims:** offline checks do not prove runtime performance or cross-engine parity.
4. **Privacy by default:** never publish customer code, records, credentials or internal measurements.
5. **Clear decisions:** preserve assumptions, alternatives, validation boundaries and recovery plans.
