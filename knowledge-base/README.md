## Principles

1. **Reproducible, not theatrical.** Publish code, fixture data, instructions, and executable checks.
2. **Correct before fast.** Verify result equivalence, including duplicated/missing rows, before claiming a speedup.
3. **Explicit limitations.** Distinguish static analysis, simulated tests, integration tests, and production evidence.
4. **Privacy by design.** Use fresh schemas, synthetic records, and domain-neutral business rules.
5. **Traceable decisions.** Record assumptions, alternatives, rollback considerations, and verification outcomes.
